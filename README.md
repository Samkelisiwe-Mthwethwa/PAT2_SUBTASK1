# Morse Code

## What is Morse Code?

Morse code is a method of communication that represents letters, numbers, and punctuation using a series of dots (.) and dashes (-). It was developed for sending messages over long distances using telegraph systems. Today, Morse code is still used by amateur radio operators, in aviation, emergency signalling, and by people learning about communication systems.

---

## History of Morse Code

Morse code was developed in the 1830s and 1840s by Samuel Morse and Alfred Vail. It was originally created for use with the electric telegraph, allowing messages to be transmitted over long distances using electrical signals.

The first official telegraph message was sent in 1844 and read:

> "What hath God wrought"

Morse code became one of the world's first international communication systems and was widely used before telephones and the internet became common.

---

## How Morse Code Works

Each letter and number has its own unique combination of dots (.) and dashes (-).

Examples:

| Letter | Morse Code |
|--------|------------|
| A | .- |
| B | -... |
| C | -.-. |
| D | -.. |
| E | . |
| F | ..-. |
| G | --. |
| H | .... |
| I | .. |
| J | .--- |

Words are separated by spaces.

Example:

HELLO

```
H = ....
E = .
L = .-..
L = .-..
O = ---
```

Message:

```
.... . .-.. .-.. ---
```

Another example:

```
SOS

... --- ...
```

This is one of the most well-known emergency distress signals.

---

## Why Morse Code is Important

Morse code is important because:

- It allows communication using simple signals.
- It can be used when voice communication is impossible.
- It is still used by amateur radio operators.
- It can be used during emergencies.
